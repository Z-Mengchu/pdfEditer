# PDF 在线编辑器

在浏览器中上传 PDF、编辑内容并重新导出为 PDF。所有处理均在本地完成，文件不上传服务器。

## 功能

- **文字编辑**：双击页面上的真实文字直接修改；可拖动移位、调整字号/颜色/加粗、擦除删除
- **元素选择**：解析 PDF 内容流中的矢量元素（图标、转曲文字块、表格线、栅格图片），可点选或框选成组，进行删除、移动（路径级矢量重绘）、替换为图片
- **框选涂抹**：拖出矩形覆盖任意区域（转曲文字/图标），可填入新文字（支持中文，自动换行、对齐）
- **文本框**：在空白处添加纯文字
- **导出 PDF**：基于原文件做定点修改，未编辑区域零失真；拉丁字符用标准字体，中文用嵌入的子集化字体

## 技术栈

React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui

- **pdfjs-dist**：页面渲染、文字层提取、内容流（operatorList）矢量元素解析
- **pdf-lib + @pdf-lib/fontkit**：PDF 导出（擦除、文字/路径/图片绘制、字体嵌入）
- **public/fonts/cjk.ttf**：文泉驿正黑子集（约 7.6MB，覆盖拉丁及全部 CJK 基本汉字 U+4E00–9FFF，简繁全含；仅在使用中文时按需加载，整体嵌入，不可二次子集化）

## 目录结构

```
src/
├── App.tsx                    # 路由入口（/ → Home）
├── main.tsx                   # React 挂载
├── pages/
│   └── Home.tsx               # 上传页 / 编辑器 状态切换
├── components/
│   ├── UploadZone.tsx         # 上传落地页（含示例文件入口）
│   ├── editor/
│   │   ├── PdfEditor.tsx      # 编辑器主体：工具栏、缩略图、状态管理、导出
│   │   ├── PageView.tsx       # 页面画布：渲染、覆盖层、拖拽/框选/元素命中
│   │   └── PropertiesPanel.tsx# 右侧属性面板（文字块/区域/元素）
│   └── ui/                    # shadcn/ui 组件库
└── lib/pdf/
    ├── types.ts               # 数据模型（文字块/区域/元素编辑）
    ├── pdfjs.ts               # PDF.js 封装：加载、渲染、文字提取、颜色采样
    ├── elements.ts            # 矢量元素解析、近邻聚簇、Path2D 命中测试
    └── exportPdf.ts           # pdf-lib 导出引擎（含中英文混排、路径重绘、图片替换）
```

## 开发

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 生产构建（输出 dist/）
```

## 已知限制

- 转曲（轮廓化）文字无法恢复为可编辑文字，只能通过涂抹覆盖后重写
- 原始栅格图片支持删除/替换，暂不支持直接拖动
- 涂抹遮盖基于外接矩形和采样底色，元素压在复杂背景上时需手动微调底色
- 页面刷新后编辑内容不保留（纯前端应用，无持久化）
